# 苏醒与 Cael 的表情包仓库

用于聊天、跨平台直链和公开备份。私密对话内容不会放进这个仓库。

## 目录

- `stickers/`：表情图片
- `manifest.json`：文件名、情绪、语气和使用场景
- `TAGS.md`：统一标签说明

## 图片直链

```text
https://cdn.jsdelivr.net/gh/sxing7714-ops/suxing-cael-stickers@main/stickers/文件名
```

Markdown 示例：

```markdown
![](https://cdn.jsdelivr.net/gh/sxing7714-ops/suxing-cael-stickers@main/stickers/hug.gif)
```

## 添加规则

1. 文件名使用小写英文或拼音，单词之间用短横线。
2. 不使用空格、中文、括号和特殊符号。
3. 新图片尽量使用新文件名，避免 CDN 缓存旧图。
4. 上传后在 `manifest.json` 中补充标题、情绪、语气与使用场景。
5. 只上传允许公开分享的图片，不放聊天记录或其他隐私内容。

## 使用方式

ChatGPT 内优先使用“星屿 · 表情匣”按语境取图；GitHub 仓库提供跨平台直链和备份。两边使用相同的文件名与标签，便于以后同步。
